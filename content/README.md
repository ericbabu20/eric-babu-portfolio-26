# Blog content (optional)

The blog is hidden while this folder contains no `.mdx` posts.

To switch it on, add a post such as `content/my-first-post.mdx`:

```mdx
---
title: "My first post"
publishedAt: "2026-11-01"
summary: "One sentence describing the post."
---

Write your post here.
```

The Blog link and the `/blog` pages appear automatically once at least one post exists.
